# OptiPath

Interaktivní inženýrský nástroj pro návrh, routování a optimalizaci optických sítí (FTTH/MDU) přímo v mapě.

## 🚀 Hlavní funkce
- **Garantované routování po uliční síti:** Využívá OSRM k trasování kabelů po skutečných cestách.
- **Plánování infrastruktury:** 
  - Páteřní trasy (OLT -> Knoten)
  - Ulice a odbočky
  - Rodinné domy (FTTH přípojky)
  - Bytové domy (MDU bloky)
- **Fyzikální bilance a rozpočet:** Automatický výpočet útlumu v decibelech (dB) a celkového finančního rozpočtu podle zvoleného typu kabelu a pokládky.
- **Export dat:** Možnost generovat oficiální BOM protokol (PDF) nebo exportovat mapu jako obrázek.
- **Vícejazyčné rozhraní:** Podpora pro češtinu, angličtinu a němčinu.
