# 🚀 OptiPath Cloud

Professional engineering web tool designed for planning, routing, and optimizing fiber optic networks (FTTH/MDU) directly on an interactive map.

## 👤 About the Author
Hi! I'm a 15-year-old developer passionate about web development, networking, and software engineering. I built **OptiPath Cloud** to solve real-world engineering challenges using modern web technologies.

## ✨ Latest Features & Capabilities
- 🗺️ **Real Street Routing**: Powered by OSRM to calculate precise cable paths along actual streets rather than straight lines.
- ☁️ **Firebase Cloud Sync**: Real-time database and user authentication to keep data synchronized seamlessly.
- 🏗️ **FTTH & MDU Infrastructure Planning**: Tools for managing backbone paths (OLT to Nodes), branch lines, single-family homes, and multi-dwelling unit apartment blocks.
- 📊 **Physical & Financial Calculations**: Automated attenuation calculation in decibels (dB) and real-time cost estimation based on cable types.
- 📄 **Export & Reporting**: Generate professional BOM (Bill of Materials) data and map snapshots.
- 🌍 **Multilingual Interface**: Built-in support for Czech, English, and German.
